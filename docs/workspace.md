# 大型參考資料夾

`services/workspace` 將遍歷、搜尋、文字解碼與 DOCX 解析移至背景 Node Worker。使用 `opendir` 與明確堆疊保留目前路徑，文字每次讀取 64 KiB；不一次載入整棵目錄或整份大文字檔。掃描不受舊版的 500 個檔案、10,000 個項目、10 層目錄限制；相容的小檔字串讀取遇到需分段內容會報錯，不再靜默截斷。

| 工具 | 行為 |
| --- | --- |
| studio_list_files | 檔名篩選與清單分頁；預設每批 100、最多 200 個 |
| studio_search_files | 獨立全文搜尋；預設每批 20、最多 50 個命中行；query 是字面文字，支援 pathQuery 與 caseSensitive |
| studio_read_file | 分段原文；預設 16,000、最多 64,000 位元組，DOCX 以字元計；回傳 nextOffset、unit、version 與 citation |
| studio_cancel_file_scan | 放棄已取得的本輪游標，關閉掃描資源 |

清單／搜尋每批約最多執行 2 秒後暫停，同時限制回傳大小。空批次仍可有下一頁；沿用回傳的 `nextCursor` 續掃相同查詢與資料夾，`null` 才表示遍歷完成。游標單次消耗、閒置 10 分鐘失效，綁定資料夾與查詢；不可跨輪或跨查詢使用。來源是即時檔案系統，不宣稱掃描期間檔案新增／刪除有資料庫快照隔離。

每個符合行回傳一個有界文字窗口、行號、可用於讀取的位置與版本。無限長的單行只保留區塊和查詢所需重疊，不建立整行字串。UTF-8／UTF-16 LE 分段會對齊完整字元；沿用 `nextOffset` 和 `version`，檔案變動時重新讀取。DOCX 壓縮檔最多 32 MB，既有解析器仍限制主文件 XML 解壓縮 4 MB；不支援的編碼、二進位、無權限或壞檔會明確回報或計入錯誤。

Worker 以節流訊息提供 visited、files、scannedFiles、bytes、matches、skipped、errorCount 及最多 20 筆錯誤。進度沿用 Agent 事件通道與 callId，工具明細保留參數及完整分頁回傳。終止 Agent 中止目前請求，結束一輪釋放其游標；應用退出終止 Worker。單一檔案存取逾時 45 秒時回報錯誤，可重新搜尋。

Agent 訊息框的 `@` 選單取代原參考檔案分頁，延遲 220 ms 後在 Worker 搜尋檔名／路徑、子資料夾及根目錄名稱；每批最多 20 筆匹配，可續掃。改變查詢、關閉或卸載選單時取消舊請求並釋放游標；過期回應不更新畫面，遲到的游標也會釋放。不建立完整樹狀索引，切換會議時不自動遍歷檔案。已知相對路徑可直接指定，經 realpath、類型、授權與格式檢查後加入。檔案格式沿用文字／程式碼及 DOCX；其他格式直接指定時明確提示需轉檔。

選單未找到檔案時仍可加入 `kind=search` 關鍵字，Agent 以實際檔名搜尋／全文搜尋工具解析來源。`kind=directory` 帶入工具 `rootId` 與 `directory` 限定遞迴子資料夾，回傳路徑仍相對於原授權根目錄；游標也綁定這個範圍。每則訊息最多 20 個來源項目，獨立於會議舊參考清單；送出前保留於草稿，接受提交後移除。引用 metadata 隨訊息、FIFO 佇列、引導文字與 request 事件保留。伺服器在提交和實際執行時重新檢查檔案／資料夾，已撤銷授權、移走或變更類型時拒絕。

搜尋專案檔案對話框仍支援檔名查詢及續掃；檔案預覽可切換上一段／下一段，版本變更後可重讀。Agent 全文搜尋獨立掃描，不受畫面目前批次限制。

保留授權根目錄、realpath 與連結檢查，略過環境憑證、Git、相依套件與建置目錄；不跟隨符號連結或 junction。此需求由 grep／cat 等效工具完成，沒有新增任意 shell 或外部檔案寫入權限。原本的時間、模型回合與工具呼叫預算繼續生效；若停止或仍有游標，Agent 不得宣稱已搜尋完所有檔案。

測試：`tests/workspace/files.test.cjs` 驗證超過 10,000 個項目、650 個文字檔、14 層目錄、8 MB 之後的命中、跨區塊與 Unicode 字元、游標、取消、版本與路徑隔離。`tests/workspace/mentions.test.cjs` 驗證文件／資料夾批次、直接路徑、搜尋範圍及來源隨排隊／引導保存且不混入下一輪。`scripts/ui/projects/files.cjs` 透過實際 Electron／本機模型模擬服務驗證 @ 分批／續掃、鍵盤選取、去重、直接路徑／越界拒絕、來源標籤、預覽分段及 Agent 搜尋後依 offset／version 深讀。
